Policy in effect

    
The file policy/merchant.yaml. The server reads it, a model never does, and its hash is written into every receipt. A prompt, a buyer message or a model reply cannot change it. This page cannot edit it.

    
version: 1
operations:
  refund:
    level: Execute within Limits
    max_amount_minor: 500
    approval_above_minor: 200
    currency: USD
    retry: never
  accept_claim:
    level: Execute within Limits
    max_amount_minor: 500
    approval_above_minor: 200
    currency: USD
    retry: never
  provide_evidence:
    level: Execute within Limits
    retry: safe
  make_offer:
    level: Execute within Limits
    max_amount_minor: 500
    approval_above_minor: 300
    currency: USD
    retry: never
  send_message:
    level: Execute within Limits
    retry: safe
  propose_resolution:
    level: Draft
    retry: never
caps:
  per_customer_per_day_minor: 600
egress:
  allow_hosts:
    - api-m.sandbox.paypal.com
