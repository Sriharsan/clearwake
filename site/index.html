Clearwake settles PayPal disputes before they turn into fees.

Agents running inside the merchant's own network resolve each case with the buyer inside the owner's limits, fight only the cases worth fighting, and never call a refund done until PayPal's own record says so.

Where the money leaks

PayPal's own rules. Each card links to the page it comes from.

1

Cases that escalate pay a fee

PayPal charges no Standard Dispute Fee when a case is resolved directly between seller and buyer and not escalated to a claim. Sellers who answer late, or only with evidence, let the case escalate.

USD 15.00 Standard Dispute Fee, US

Rule: PayPal Help Center, help350 (UK edition; the US edition was not reachable when checked). Fee: PayPal Merchant Fees, US, updated 1 Oct 2026.

2

A high dispute rate doubles it

A seller with more than 100 sales in the previous 3 months and a dispute rate of 1.5% or more pays the High Volume Dispute Fee on every dispute.

USD 30.00 High Volume Dispute Fee, US

Rule: help350. Fee: PayPal Merchant Fees, US.

3

A refund sent twice, or one that silently failed

Either costs money or a customer. Clearwake gives each refund one stable request id, holds any reply it cannot confirm as UNKNOWN, and only reports a refund once PayPal's refund record matches.

1 request per refund, checked against PayPal

Shown in the recorded sandbox run below.

The Standard fee is also not charged on claims below twice the fee or on unauthorised transactions, so Clearwake counts a fee avoided only when PayPal's rule would otherwise have charged it.

The boundary

The live system runs in a network isolated container network on the merchant's own machine. One gateway is the only way out.

What stays inside and what crosses the gateway

Dispute text, buyer messages, evidence draftsOnly what PayPal's API needs for the step: a message, an offer amount, tracking factsCustomer data and dispute evidence stay inside the merchant's environment
Policy file, approvals, limitsNothingA buyer message or a model reply cannot change a limit

Run it on your machine

Python 3.12 or newer, nothing to install. Starts in rehearsal with invented records and makes no network calls.

git clone --recurse-submodules https://github.com/Sriharsan/clearwake.git
cd clearwake
python -m clearwake --port 8810

Then open 127.0.0.1:8810/console. The isolated network run is python scripts/airgap.py (Docker and your own sandbox keys).
