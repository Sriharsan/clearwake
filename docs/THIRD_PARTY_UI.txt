Third party code served by the Clearwake console (/console)
=============================================================

The console loads nothing from any other host. Everything it serves is in
this repository.

             (the downloaded tarball hashed to the same value on 31 October 2026)
  Used for:  the dispute ledger in the merchant control room
  CSP:       version 33 and later set row and cell positions through the CSS object model and take a

             'unsafe-inline'. Checked in Chromium on 31 October 2026: zero CSP violations, rows drawn
             correctly. Other console tables stay plain HTML.

  Tried:     31 October 2026, the "noStyle" build with ag-grid.min.css and
             ag-theme-quartz-no-font.min.css, served from this machine.
  Result:    the grid builds rows from HTML templates that carry inline style
             attributes. The console's Content Security Policy (style-src 'self',

             was not loosened.
